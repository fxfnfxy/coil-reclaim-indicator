# coil-reclaim-indicator · 两根K线定方向

一个 TradingView 指标（Pine Script v5），把一套「方向 → 区域 → 触发」的时段交易规则全部画在图上，每一步都用 JSON 数据包发出来，交给 Grok Bot 或 Claude 按同一套规则复核，给出 LONG、SHORT 或 SKIP。

只在亚盘、伦敦盘、纽约开盘各自的第一个小时找机会。所有计算都在K线收盘后进行，高周期只读已经收盘的K线，不重绘。

## 规则

方向
1. 看两根K线：昨天的日线，和时段开始前最后一根收盘的 4 小时K线。
2. 两根都是阳线只做多，两根都是阴线只做空。
3. 颜色不一致时：顶在日线天花板只做空，踩在日线地板只做多；都不是就看周线台阶（高点低点都抬高算向上）；还看不出来就跟昨天日线。也可以在设置里改成「日线为准」或「观望」。
4. 方向在时段第一根K线定下，整段不变。

区域
5. 天花板和地板画在K线实体上：阳线后接阴线是天花板，阴线后接阳线是地板。只有本周期K线收盘穿过才算破（日线价位要日线收盘）。
6. 顺方向顶到日线价位（做多碰到日线天花板，做空碰到日线地板），今天不再做这个方向，明天再来。
7. 只在干净区里做：同向K线连着走至少 3 根、幅度至少 1.5 倍 ATR 的那段行情。里面新长出 4 小时或 1 小时价位，这个区就失效。
8. 盘前那根 4 小时K线已经顺方向走完（实体占振幅 60% 以上，振幅至少 1 倍 4 小时 ATR），就等回调：区间要回到那根K线的 38.2% 以内才算数。

触发
9. 只在每个时段的第一个小时：亚盘 09:00 东京、伦敦 08:00 伦敦、纽约 09:30 纽约，夏令时自动跟。
10. 先有区间：3 到 20 根K线，里面至少 2 根反向K线，高度在 0.5 到 4 倍 ATR 之间。
11. 再有突破K线：顺方向、实体至少占振幅一半、收在区间外，振幅不超过区间高度的一半。
12. 突破后在突破K线高点挂买入止损单（做空挂低点），止损放在突破K线另一端外侧。
13. 先回踩再成交（橡皮筋）：要先出现一根有像样下影线的K线（做空看上影线），再碰到挂单价才成交。没回踩就直接突破的作废；收回区间里作废；6 根K线没成交作废。

出场
14. 到 1R 平一半，止损挪到进场价。1R 之前先碰到别的价位，也挪到进场价。
15. 剩下的拿到下一个未破的天花板或地板（日线、4 小时、1 小时里最近的那个），最远 3R。
16. 浮盈到 1.5R 且连续 3 根同向K线，算走太快，直接止盈。持仓超过 240 分钟按收盘价出场。
17. 每个时段最多 2 笔，同一时间只有 1 笔。每笔风险 % 在设置里填，只写进数据包给 Agent 算仓位。

所有数字都是设置里的默认值，可以改。

## 上手

第 1 步：加指标
1. 打开 `coil_reclaim.pine`，全部复制。
2. TradingView 图表底部打开 Pine Editor，先 Ctrl + A 把默认代码删干净，再粘贴。
3. 保存，点「添加到图表」。先用 15 分钟图看熟，再换 5 分钟。

第 2 步：建警报
1. 打开警报窗口（Alt + A）。
2. 条件选 `Coil Reclaim · 两根K线定方向`，下面选「任何 alert() 函数调用」（Any alert() function call）。
3. 通知里勾 Webhook URL，填第 3 步的地址。消息框不用改，指标自己写内容。
4. 一个警报管一张图（一个品种、一个周期），要看几张图就建几个。
5. Webhook 需要 TradingView 付费版，并且开了两步验证。

第 3 步：接收数据包
```bash
# 终端 1：启动接收器（Python 3，不用装东西）
python3 examples/webhook_receiver.py --port 8080 --token 你的密码

# 终端 2：给它一个 https 地址
cloudflared tunnel --url http://localhost:8080
```
Webhook URL 填 `https://<隧道地址>/webhook?token=你的密码`。每个包都会存进 `packets/`，最新一个在 `packets/latest.json`，全部历史在 `packets/all.jsonl`。

第 4 步：交给 Agent
把 `agent/AGENT_PROMPT.md` 里的提示词给 Grok Bot 或 Claude，然后说：

```
按 agent/AGENT_PROMPT.md，读 packets/latest.json，给我这个事件的结论。
```

不跑接收器也可以，直接把警报里的 JSON 复制给它。

## 图上有什么

- 右上角状态表：方向（两根K线、台阶、方向和原因）、区域（位置、日线天花板和地板、干净区、盘前 4 小时、今天能不能做）、触发（区间、回踩、状态、上次跳过的原因）、持仓（止损、1R、目标、浮动 R）。
- 首小时窗口按方向染色，开盘第一根打方向标签。
- 区间框、`① 突破`、挂单虚线、`② 橡皮筋 ↺`、`③ 进场`、止损 / 1R / 目标线、`🛡 保本`、出场结果（单位 R）。
- 灰色 `✕` 标签写着为什么跳过：明天再来、突破K线太大、等回调、不在干净区、没先回踩。

## 24/7 盯盘机器人（`bot/`）

仓库里多了一个可以常驻的机器人：把警报数据包接进来，按 `agent/AGENT_PROMPT.md` 的规则**逐条**复核，
给出 `LONG / SHORT / SKIP`，算好仓位，推到手机，全程记账。指标本身一行没改。

```bash
cd bot                                 # 必须在仓库根目录先进入 bot/（或写全路径）
cp config.example.toml config.toml     # 填 [server] token 与 [notify]（Telegram/钉钉/飞书/邮件）
python -m coilbot doctor               # 自检
./tunnel.ps1                           # 给 TradingView 一个 https 地址（自动装 cloudflared）
python -m coilbot serve                # 常驻；或 ./install_service.ps1 注册成计划任务（登录自启+崩溃重启）
```

Windows 上不想敲命令：双击 `bot\控制台.cmd`，菜单里有自检 / 启动 / 状态 / 测试通知 / 起隧道 / 计划任务。

| 能力 | 说明 |
|---|---|
| 规则复核 | 方向→区域→触发→仓位 13 条硬规则，逐条打印「过/不过」，全过才给方向 |
| 仓位 | 风险 % → 数量（按品种步长向下取整），1R / 目标 R，名义上限 |
| 通知 | Telegram / 钉钉 / 企微 / 飞书 / 邮件 / Windows 弹窗，单通道失败不影响主流程 |
| 稳定 | token + 限流 + 幂等去重 + 原始包归档 + `/health`；守护线程管心跳、静默告警、每日战报 |
| 执行 | `signal`（默认，只发信号）/ `paper`（记账统计）/ `live`（币安合约，默认 dry_run） |

细节、配置项与排障见 [`bot/README.md`](bot/README.md)。
